# LUNA – Get home safe

Website for LUNA, the evening minibus for women and girls of every age, driven by women, in Marseille.
Student Impact Project – KEDGE Business School (Camélia, Philémon, Janelle, Jihane, Antoine).

Static site: open `index.html`, or publish it with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

To connect the booking buttons to a real WhatsApp number, set `const WHATSAPP = "33XXXXXXXXX";` near the top of the script in `index.html`.
